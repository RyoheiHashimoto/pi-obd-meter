# ATF 油温の実測記録

0x17B3 で油温が取れるようになって分かったこと。**一般論と食い違う点が複数ある。**

## 1. 何が油温を上げるのか

滑りでもロックアップ状態でもなく、**伝えている動力**が支配する。
燃料消費レートを物差しにすると、きれいな一次関係になる。

```
油温の上昇率 (℃/分) = 0.093 × 燃料消費レート (L/h) − 0.88
→ 平衡点 9.4 L/h
```

**9.4 L/h を超えて走り続けると油温は上がり続ける。** 下回れば下がる。
(油温 105〜118℃ の帯で当てはめた式。油温が違えば放熱量も変わる)

## 2. 実測 — 首都高と新東名で別物

| | 首都高 (52分) | 新東名 (117分) |
|---|---|---|
| 最高油温 | 99.9℃ | **114.8℃** |
| 平衡したか | **約100℃で頭打ち** | **最後まで上がり続けた** |
| 100℃以上 | 0分 | 76分 |
| 110℃以上 | 0分 | 19分 |
| 平衡点超えの時間 | 少ない | 43分 / 115分 |

水温はどちらも 86〜99℃ で正常域。**油だけが離れていく。**
新東名では水温との差が +23.0℃ まで開いた。

## 2b. オープンループ (増量制御) が3分の1

高負荷では ECU が O2 センサーを無視して燃料を濃くする (12〜13:1)。
余分な燃料が気化熱で燃焼室・排気バルブ・触媒を冷やす、**設計どおりの保護動作。**

標準 PID 0x03 (燃料システム状態) で判別できる。

| 状態 | 割合 | 平均車速 |
|---|---|---|
| クローズドループ (2) | 65.7% | 58 km/h |
| **オープンループ増量 (4)** | **34.3%** | **106 km/h** |

**新東名の3分の1は増量制御中だった。** 1.3L・91馬力で 1100kg を 120km/h 超で
押し続ける以上、持てる力の大半を使うことになる。

これが2つの結果に直結する。

- **燃費 8.03 km/L** (普段の平均 11.5 に対して)
- **油温の上昇** — 濃くするほど出力が出て、通る動力が増えて熱になる

Mode 22 側にも `0x1678` (オープンループフラグ) と `0x1631` (クローズドループ)
があり、0x03 と 83% 一致する。**1678 が ON のとき短期燃料トリムの 85% が
0% に凍結する**ことで確認した (フィードバックを止めている証拠)。

## 3. 一般論と食い違う点

### 渋滞は熱くない

「真夏の渋滞が最悪」は**この車では成り立たない。**

| 走行状態 | 上昇率 | 水温との差 |
|---|---|---|
| 渋滞・低速 | **−0.07℃/分** | −3.9℃ |
| 中速 | +0.13℃/分 | −1.4℃ |
| **高速** | **+1.22℃/分** | −2.0℃ |

15分の渋滞で 91.5 → 92.4℃ とほぼ横ばい。その間に水温は 100℃ まで上がった。
ロックはほぼ全解放 (4%) なのに熱くならない。**滑っていても、伝えている動力が
小さければ熱は出ない。** 発熱は「滑り × トルク」なので。

### 3速 HOLD は油温を上げない

油温を揃えて比較すると、**回転が高くても 3速の方が涼しい。**

| 状態 | 上昇率 | 滑り比 | 平均rpm |
|---|---|---|---|
| スロットル50%超 | **+1.09℃/分** | — | — |
| 4速ロックON | +0.31℃/分 | 1.001 | 2420 |
| 4速解放 | −0.62℃/分 | 1.060 | 2566 |
| **3速 HOLD** | **−0.41℃/分** | 1.016 | 3307 |

高速比ではトルコンが結合点に近く、滑りが 1.6% しかない。
熱を作っているのは**踏んでいる量そのもの。**

### 停車後の冷却

```
アイドリングで −1.39℃/分  (SA停車 5.4分で 108.3 → 100.8℃)
```

100℃から90℃まで約7分。**走行後に少し止めておくのは有効だが、5分で十分。**
それ以上は効果が薄れる。

## 4. 温度と寿命の目安

| 温度 | 何が起きるか |
|---|---|
| 79〜93℃ | 理想。油の寿命が最も長い |
| 〜107℃ | 許容範囲 |
| **115℃ (240°F)** | **ベースオイルの酸化開始。シール硬化。添加剤が焼け始める** |
| 130℃ | 酸化が急加速 |

93℃ (200°F) を超えると 11℃ ごとに寿命が半減する、という経験則がある。
新東名の 2時間は通常走行 8時間分に相当する。

**問題になるのは常態化した場合。** 文献が警告しているのは「日常的に 240°F で
走っている」状態であり、年に数回なら誤差。

## 5. 交換の目安

マツダ公式は定期交換不要。ディーラーは非公式に 6〜7万km を勧めることがある。
新東名の全開走行が常態化するなら 4.5〜5万km で見る価値がある。

**距離だけでなく熱履歴で見た方が正確。** 油温を記録しているので、
「何℃で何時間走ったか」で判断できる。

# メーター表示指標ガイド

車載メーター（800×480 LCD）に表示される各指標の意味と、運転中の活用方法。

## ゲージ内アーク

速度ゲージの内側にスロットルアークを1本表示。

### スロットル

- **何を見てるか**: アクセルペダルの踏み込み量（スロットルバルブ開度）。ドライバーの入力そのもの。
- **範囲**: config の `throttle_idle_pct` を 0%、`throttle_max_pct` を 100% として正規化
- **使い方**: アクセル操作の可視化。踏み込み量と加速の対応を客観的に確認できる。

## 右パネル

速度ゲージの右側に配置。上部にバキューム計、下部に4行インジケーター。

### バキューム計

- **表示**: MAP (kPa) を Bar に変換した負圧ゲージ (-1.0〜0 Bar)
- **変換式**: `bar = (MAP - 101.3) / 100`
- **使い方**: エンジンブレーキの強さやスロットル状態を直感的に把握。負圧が深いほどスロットルが閉じている

### 瞬間燃費（バキューム計の中、針の付け根の上）

以前 VACUUM ラベルがあった位置に出す（2026-10-02）。下半分の「数値 / Bar」と同じく、数字の下に単位を置いて中央にそろえる。

- **表示値**: 直近2秒の距離と燃料をそれぞれ合計して割った値。数字は1秒ごとに書き換える
  - 走行中 (`fuel_economy` > 0): km/L、小数2桁、上限 99.99
  - 停車・10 km/h 未満 (`fuel_economy` = 0): 燃料流量 L/h、小数2桁
  - エンブレ判定 (`fuel_economy` = -1)・ACC OFF: `--`。判定中の値は2秒の合計にも入れない
- **色**: 数字だけに付け、毎回書き換える。走行中は値で 0 km/L = 赤 → `eco_gradient_max_kmpl` = 緑。停車中・エンブレ判定中はバキューム計と同じ色。
  単位 (km/L・L/h) は他の単位 (Bar など) と同じ書体で白。大きさは 20 (数字が 26 と小さく、24 では単位が数字と同じくらいに見えたため)
- **書き換えを1秒ごとにした理由**: 2026-09-17〜28 の走行ログ (10 km/h 以上で約20時間) で数えると、0.4秒ごとなら数字が1秒に2.4回変わって読めない。
  MIL-STD-1472F は「確実に読ませたい数字は毎秒1回より速く更新しない」。マツダ純正・ScanGauge は約2秒ごと
- 仕様の根拠（エンブレ判定の外れ率、L/h に切り替える理由）は `docs/calculation-logic.md` の「瞬間燃費を画面に数値で出すときの仕様」

### 4行インジケーター

#### ECO — 燃費

- **表示値**: 給油間の平均燃費 (km/L、`avg_fuel_economy`)
- **色**: 平均燃費の値で連続的に変わる（0 km/L = 赤 → `eco_gradient_max_kmpl` 以上 = 緑）。平均がまだ無いときは白。
  2026-10-02 までは色だけ瞬間燃費で決めていて、数字と色が別の値を指していた
- **使い方**: 総合的な燃費の良し悪し。色が緑に近いほど効率的

#### TEMP — 冷却水温

- **表示値**: 冷却水温 (°C)
- **色**: 青 (〜60°C 暖機中) → 緑 (60〜100°C 正常) → 橙 (101〜104°C 注意) → 赤 (105°C〜 過熱)
- **使い方**: 始動直後の暖機完了確認。105°C 超えは即対処が必要

#### TRIP — 走行距離

- **表示値**: 前回給油からの走行距離 (km)
- **ドット色**: 緑 → 橙 → 赤（給油タイミングの目安）
- **使い方**: ガソリン残量の目安

#### OIL — オイル交換

- **表示**: オイル交換距離に応じた進捗
- **色**: 緑 (正常) → 黄 (warning_km 到達) → 橙 (interval_km 到達) → 赤 (danger_km 超過)
- **使い方**: オイル交換時期の通知。config の `oil_change` で閾値を設定

## 運転シナリオ別ガイド

### 普段の運転

バキューム計の中の瞬間燃費の色を見る。緑ならOK。ECO 行の色は給油間の平均なのでゆっくりしか動かない。

### 信号待ち → 発進

穏やかなアクセルでスロットルアークの跳ね上がりを抑える。

## 表示しない指標

| 指標 | 非表示の理由 |
|---|---|
| RPM | ReadFast を2PIDに絞るため削除。ReadAll（2.5秒間隔）でのみ取得 |
| kPa（インマニ圧）アーク | 同上。ELM327マルチPID非対応で表示更新が追いつかない (Issue #54) |
| L/h（燃料消費レート）アーク | 同上 |
| エンジン負荷 (%) | kPa とほぼ同じ動きをする。独自の有用情報がない |
| 推定トルク / 馬力 | OBD データからの推定精度が ±30%。不正確な数値は判断を誤らせる |
| ギア段表示 | CAN 0x230/0x231 から直接取得し、速度ゲージ内にレンジ/ギア番号として表示 |

## データ配信

メーター UI は WebSocket (`/ws/realtime`) を優先接続し、接続失敗時は HTTP (`/api/realtime`) にフォールバックする。

## OBDデータ更新頻度

| 項目 | 更新間隔 | 読み取り元 |
|---|---|---|
| 速度 | ~200ms | ReadFast (毎サイクル) |
| スロットル | ~200ms | ReadFast (毎サイクル) |
| ECO (燃費) | ~1秒 | ReadAll (5サイクルに1回) で再計算 |
| TRIP | ~200ms | 車速積分 (毎サイクル) |
| TEMP (水温) | ~1秒 | ReadAll (5サイクルに1回) |
| RPM / 負荷 / MAP / MAF | ~1秒 | ReadAll (内部計算用、非表示) |

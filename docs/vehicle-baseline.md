# この車の正常値 (2026-08 実測)

**「おかしいかも」と思ったときの比較対象。** 一般論を当てはめる前にここを見る。

対象: デミオ DY3W / ZJ-VE / FN4A-EL / 走行 10.9万km / 20年落ち

---

## 諸元

```
エンジン  ZJ-VE 1348cc 直4 DOHC 圧縮比10.0  S-VT (吸気カムのベーン式可変バルブ)
出力      91 PS (67 kW) / 6000 rpm
トルク    124 N·m (12.6 kgm) / 3500 rpm
変速機    FN4A-EL (Ford 4F27E) 4速AT
指定油    エンジンオイル 0W-20
タイヤ    185/55R15 82V ヨコハマ BluEarth-GT AE51 (純正 175/65R14 から変更。外径差 0.2%)
```

**S-VT は油圧で動く。** エンジンオイルは潤滑だけでなく作動油でもあるので、
粘度を変えると応答に影響しうる。

### 吸気圧はエアコンで大きく変わる

**混ぜて平均してはいけない。** アイドリング時の分布が3つの山に分かれる。

```
29〜32 kPa   30%   素の状態
41〜47 kPa   39%   何かが1つ乗っている
57〜63 kPa   21%   さらに乗っている
```

エアコンON時は消費が 0.75 → 1.50 L/h と倍になり、回転も 712 → 755 rpm に上がる。
**エアコンを分離せずに平均すると 43.5 kPa となり「やや高い」と誤判定する。**
実際に一度それをやった。

## 水温 — この車は元々高い

**一般論を当てはめて「98℃は高め」と誤判定した。** マツダ ZJ 系の設計値:

```
サーモスタット  開き始め 80〜84℃ / 全開 95℃
電動ファン      約100℃で高速 → 90℃まで下げる
```

**95℃は「異常」ではなく「設計上の全開点」。** 同じデミオの実測報告でも
街乗り 89℃、ラリー走行後で 103℃ とされている。

実測: 走行中の平均 91.4℃、最高 99℃ (渋滞時)。**完全に正常域。**

## 電気系 — 充電制御車である

**DY3W は充電制御車。** バッテリーは充電制御対応品が必要 (純正相当 55D23L)。

電圧が連続的でなく**二値に分かれる**のが特徴。中間がほとんど無い。

```
12.8〜13.0V  35%   抑制モード
13.5〜13.9V  60%   充電モード
13.1〜13.4V   5%   遷移中のみ
```

切り替えの条件も設計どおり。**軽加速のときだけ発電を絞る。**

| 状況 | 充電モード率 |
|---|---|
| 停車 | 78% |
| 加速25%超 | 69% |
| 減速・惰行 | 57% |
| 巡航 | 49% |
| **軽加速(10-25%)** | **30%** |

### 基準値 (2025-08 交換の caos で1年経過時点)

```
充電モード率  63〜64%   (2走行で再現)
アイドル電圧  13.58V    (回転が低いほど高い = オルタネータ正常)
最低電圧      12.65V
```

一般に充電制御車の充電モードは走行中の 1/4〜1/3 とされるが、**大容量品では
長くなる**。劣化すると内部抵抗が上がって充電制御が効かなくなり、この比率が
上がっていく。**年単位で追えば劣化の指標になる。**

## 変速機の速度と回転数

```
rpm = 車速 × ギア比 × 38.8
機械ギア比  1速 2.816 / 2速 1.498 / 3速 1.000 / 4速 0.726
```

定数 38.8 は「(1000/60) ÷ タイヤ周長 × 最終減速比」。
**ロックアップ中は剛結合なので、この式が厳密に成り立つ。**
`internal/can/slip.go` の `SlipCalibrator` はここから k を自動学習する。

| 車速 | 1速 | 2速 | 3速 | 4速 |
|---|---|---|---|---|
| 50 | 5481 | 2915 | 1946 | 1413 |
| **60** | — | **3499** | 2336 | 1696 |
| 80 | — | 4665 | 3114 | 2261 |
| **90** | — | 5248 | **3503** | 2543 |

**2速60km/h と 3速90km/h がトルクピーク(3500rpm)にちょうど乗る。**
峠で2〜3速を使うのは、この車の一番おいしい帯域を使っていることになる。

## 燃料センダーの限界

**両端でクリップする。** 給油量の自動算出が原理的に不正確になる原因。

```
下端  raw 22  (8.6%)
上端  raw 243 (95.3%)
```

満タン給油後、**11分間 95.29pt に張り付いたまま**で、燃料が減って測定範囲に
戻ってから初めて 90.6pt という実測値になった。**満タン時の読みは「上限に
達した」以上の情報を持たない。**

**係数 0.51 L/pt は中域でしか正しくない。** タンクは箱ではなく高さで断面積が
変わるため非線形。全域を跨いだ給油では 0.442 L/pt となり 13% ずれた
(実測 35.29L に対し 40.69L と算出、+15%)。

→ 満タン時は給油量を出さない実装にした (#148)。跳躍量は較正の材料として残す。

## 動力性能の推定方法とその限界

トルクセンサーは無いが、加速度から逆算できる。**ただし限界がある。**

```
F = m(1+λ)a + Crr·m·g + ½ρ·CdA·v²
T_engine = F × (r/FD) ÷ (機械ギア比 × η × K)

m=1220kg(車両重量 1080 + 2人) / λ=0.07(回転慣性) / Crr=0.012 / CdA=0.676
η=0.88(駆動系効率) / K=トルコン増幅 (滑りから概算、ロック時1.0)
r/FD は k から逆算: 1/(2π×0.06×k) = 0.0684 m
```

実測結果 (2026-08-28 の新東名 `drive-0828-2204.csv`、2人乗車。MAP≥95kPa = 全開、
3速のみ、加速中):

| rpm | 最大トルク | カタログ | 比 |
|---|---|---|---|
| 3750-4000 | 126.9 N·m | 122 | 104% |
| 4000-4250 | 129.2 N·m | 122 | **106%** |
| 4250-4500 | 128.6 N·m | 120 | 107% |
| 5000-5250 | 111.0 N·m | 114 | 97% |

**トルクは落ちていない (カタログ比 97〜107%)。** 100% を超える分は「カタログ以上」
ではなく推定の誤差。仮定が5つ入っており、それぞれ ±10%動けば推定値も±10%動く。
**0.5%の勾配だけで3%動く**が、8月は勾配を補正できていない (IMU も GPS もまだ無い)。

**2026-10-12 の関越 (2人乗車、m=1220kg) では IMU で勾配を補正できた。** 同じ式・同じ
条件で 3750-4000 119.7 / 4000-4250 119.0 / 4250-4500 113.2 / 4500-4750 107.3 N·m
(カタログ比 91〜98%)。勾配を入れないと 86〜94% で、1〜3% の上りで加速した場面が多かった。
標高 (最高 670m) で空気が薄い分も低めに出る。8月の 100% 超えは、下りぎみの場面を拾った
可能性がある。

**2026-10-13 訂正:** 当初は m=1100kg (乗員込) で計算し、116.4 / 118.9 / 118.4 /
103.9 N·m (カタログ比 91〜99%、「3〜9%落ち」) と書いていた。この車の車両重量は
1080kg (2004年6月のコージー) で、この走行は2人乗車だったので、1100kg は軽すぎた。
同じスクリプト・同じデータで m だけを 1220kg に直した (加速と転がり抵抗の項が m に
比例し、空気抵抗は変わらない)。

### 使えるのは最大値だけ。中央値は無意味

同じ rpm・同じ MAP でも観測トルクは 46〜129 N·m (3750〜4500rpm) とばらつく。理由は2つ。

1. **勾配** — 登坂中は重力に食われて加速しない
2. **最高速付近** — 全開でも加速しない (3速なら 135km/h 付近)。
   このとき測っているのは空気抵抗との釣り合いであって、エンジンの実力ではない

**低回転側はとくに危険。** 3速で低回転 = 低速であり、全開で15秒経っても
84km/h のままなら**それは登坂中**。そういうサンプルしか無い帯域では
トルクカーブが引けない。実際 3500rpm 以下は平坦路データが皆無だった。

### 勾配は分離できない

加速の不足分から勾配を逆算しようとしたが、**全サンプルが +0.1〜+15.9%
(中央値 +5.8%) となり成立しなかった。** 高速道路の勾配は通常 2〜3% で、
16% はありえない。

原因は上記の「最高速付近では全開でも加速しない」問題と、
**スロットル開度がトルクの指標にならない**こと (70%と90%でトルクが違う)。
MAP で絞っても、最高速付近の非加速状態と登坂を区別できない。

**勾配が要るなら GPS (#110) を入れること。** 現在の記録項目では届かない。

## 山道での性能 (2026-10-12、魚沼スカイライン)

スカイラインの上り・山頂付近・尾根・下り (約 32km) を、IMU・4 輪の車輪速・CAN で
突き合わせた。**2 人乗車。** 勾配の出し方は [imu.md](imu.md)、ギアの選び方は
[at-shift-points.md](at-shift-points.md) の「急な上り坂」。

**まとめ: タイヤの力は一般的な限界の 6〜7 割まで。後ろは流れず、前輪も空転して
いない。力はギアが合っていれば足りる** (1 速なら登れる坂 21% > この日の最急 15.5%)。
足りなかったのは L の 2 速で 2,400rpm 前後のときだけ。

### グリップ

横 G は 車速 × IMU のヨーレート、前後 G は CAN の車速の 0.5 秒差分。どちらも 0.5 秒平均。

| | 値 |
|---|---|
| 横 G の最大 | **0.53 G** (下り、半径 18m を 34km/h、ブレーキ中) |
| 0.4 G 超 / 0.5 G 超 | 合計 44 秒 / 1.6 秒 |
| 加速の最大 / 減速の最大 | +0.26 G / −0.38 G |

- 一般的な乗用車のタイヤは乾いた舗装で 0.8 G 前後が限界と言われる。その 6〜7 割
- **後ろが流れた形跡は無い。** FF の後輪は駆動しないので、左右の車輪速の差 ÷ トレッドが
  ヨーレートになる (当てはめたトレッド 1.50m、IMU と相関 0.961)。IMU とのずれは
  横 0.4〜0.6 G でも直線と同じ ±3°/s の幅に収まっていた
- アンダーステアはハンドル角を記録していないので測れない
- IMU のヨーレートの感度は GPS の進路の変化と比べて 0.964 倍。横 G は 4% 以内の誤差を含む

## 高回転と力 (2026-10-14)

### 回し方と健康状態

| | 9 月 | 10/8 以降 |
|---|---|---|
| 4000rpm 以上の時間 | 0〜1% (9/20 だけ 1.9%) | 1.1〜1.7% |
| 5000rpm 以上の時間 | ほぼ 0% | 10/14 は 0.22% (約 23 秒) |
| 最高回転 | 6284 (9/20) | 6485 (10/16、記録で最高。リミッターは下の節) |

5000rpm 超は 2 種類だけで、どれも数秒: L + HOLD (1 速) を全開で引っ張って S + HOLD
(2 速) に入れる場面 (6055〜6461rpm) と、D + HOLD (3 速) を 85〜98km/h まで引っ張る場面
(〜5850rpm)。回すようになっても、故障コード 0、長期燃料補正は日ごとの中央値で
−2.3〜+2.3%、全開時の点火時期は中央値 12〜14.5° で変わらない (ノッキングで遅らせて
いる形跡が無い)。水温 ≤101℃、ATF ≤101℃。オイルの温度・量は記録していない。

### 1 速は頂点まで 1 速のまま

`shifting` はレバーを動かした時点で立つが、実際のギア比 (回転 ÷ 後輪の車速) は
頂点まで 1 速 (2.86〜2.89、トルコンの滑り込み) のままで、2 速へ動き始めるのは頂点の
約 0.2 秒後。レバーから実際の変速まで 0.4〜0.6 秒あり、その間に回転が 300〜450rpm
伸びる (レバー 5800〜6000rpm → 頂点 6050〜6460rpm)。リミッターには当たっていない
(燃料は 24〜26L/h 出続け、車速も伸び続ける)。頂点を 6000rpm 前後にしたいなら、
レバーは 5600rpm くらい。

**最後の 0.2〜0.4 秒は加速が 1〜4 割落ちる**が、落ち始めは回転ではなく時間で決まる
(頂点 6055 の回も 6461 の回も、ギア比が変わる直前で落ちる)。AT の中で 2 速側の
クラッチが力を受け持ち始める段階と考えられ、エンジンの力ではない。

### リミッター (2026-10-16)

L + HOLD (1 速) のまま全開で引っ張ると、6,420rpm (57.7km/h) までは加速が約 2.0 m/s² のまま
落ちず、そこで回転が止まった。その後 0.6 秒、回転は 6,403〜6,456rpm から上がらず、加速は
0.4 秒で 2.0 → 0.8 → 0.5 → 0.3 m/s² に落ちた (車速は 57.7 → 59.5km/h と惰性で少し伸びる)。
**リミッターは 6,450rpm 前後で効く。** 10/14 の頂点 6,461rpm は変速中の一瞬で、回転は止まらずに
2 速へ移っていた。

リミッターに当てずに 1 速を使い切るなら、レバーの遅れ (0.4〜0.6 秒、+300〜450rpm) を見込んで
5,900〜6,000rpm でレバーを S に入れる。頂点が 6,300〜6,400rpm になる。S レンジ (HOLD 無し) に
任せると、全開でも車は 5,820rpm で 2 速に上げる ([at-shift-points.md](at-shift-points.md))。
差は 60km/h までで 0.2〜0.3 秒ほど (目安)。

### 6400rpm までは馬力が伸びている

1 速・全開の加速 (後輪の車速、0.4 秒差分) × 回転を馬力の目安にして比べた。上の
クラッチの段階より前だけを使う。

| 走行 | 5500〜5900rpm | 6000〜6250rpm | 馬力の目安の差 |
|---|---|---|---|
| 10/14 早朝 (頂点 6452) | 2.15 m/s² | 2.12 m/s² | +6% |
| 10/14 昼 (頂点 6461) | 1.73 | 1.75 | +10% |
| 10/10 (頂点 6354) | 2.00 | 2.06 | +11% |

カタログの最大出力 (91PS / 6000rpm) から 6000rpm のトルクは約 106N·m で、5500 →
6000rpm でカタログ上も馬力は約 7% 伸びる。実測はこれと合う。1 速のトルクは 4000 →
6000rpm で約 20% 下がる (カタログは約 13%)。トルクの山は 3 速の推定で 3000〜4000rpm。
**カタログより高回転寄りとは言えない。** ワゴリス (下) の効果は 1〜2% で見分けられない。

10/16 の L + HOLD の回 (上のリミッターまで) では、5,000〜6,420rpm の加速が 1.95〜2.19 m/s² で
ほぼ一定だった。回転が上がっても加速が落ちないので、馬力の目安は 6,400rpm まで伸びている
(10/14 までは 6,250rpm までしか見られていなかった)。

### 10/12 と 10/14 の力の比較

2・3 速の全開加速から、上の「動力性能の推定方法」の式でトルクを出した。λ は 3 速
0.07・2 速 0.12 (エンジン側の慣性をギア比の 2 乗で増やした推定)、滑りが 1.10 以下なら
トルコンの増幅は 1.0。勾配は IMU、その日の IMU のずれを GPS の 60 秒窓で直した
(10/12 −0.31%、10/14 +0.27%。勾配が 1% ずれるとトルクは約 7% 動く)。

| 3 速 | 10/12 (2人、1220kg) | 10/14 (1人、1150kg) |
|---|---|---|
| 3500〜4000rpm | 120.5 N·m | 132.9 N·m |
| 4000〜4500rpm | 120.5 N·m | 128.6 N·m |
| 4500〜5000rpm | 116.3 N·m | 118.8 N·m |

全開時の吸気圧と吸気温から、10/14 (早朝・低地) は吸える空気が 3.1% 多い。それを除くと
差は −1〜+7% で、全開加速 1 回ごとのぶれ (坂を補正して ±8%) の中。2 日の力は同じ。
5000〜5500rpm でエンジン出力換算 80〜85PS。

### ベタ踏みと 1 速の力 (2026-10-16)

ここまで「全開」としてきたのは吸気圧 90kPa 以上の区間で、アクセル (0x201 B6) は 92〜122 だった。
床まで踏むと 197 になる (9/10・9/18 のキックダウン、10/16 夜)。10/16 夜に S レンジで床まで踏み、
1 速の加速を前の回と並べた。加速は後輪の車速の 0.4 秒差分を IMU の坂で平らに直したもの。
IMU の坂のずれは走行ごとに GPS の 60 秒窓で出して差し引いた (10/16 は 2 本とも大きい、
[imu.md](imu.md))。全員 1 人乗り。

| 走行 | アクセル | 吸気圧 / 外気圧 (kPa) | 1 回転の空気 | 坂 | 4000〜4500 | 4500〜5000 | 5000〜5500 | 5500〜5950rpm |
|---|---|---|---|---|---|---|---|---|
| 10/14 早朝 | 115 | 97.5 / 101.1 (96%) | 11.50 | +1.5% | 2.92 | 2.60 | 2.34 | 2.30 m/s² |
| 10/14 昼 | 92〜122 | 90.5 / 96.4 (94%) | 10.88 | +3.3% | — | 2.51 | 2.06 | 1.98 |
| 10/16 昼 | 104〜106 | 94.5 / 98.3 (96%) | 10.76 | +1.7% | 2.67 | 2.42 | 2.24 | 2.16 |
| **10/16 夜 (床まで)** | **197** | 98.2 / 98.5 (100%) | 11.31 | +4.0% | 2.72 | 2.43 | 2.41 | 2.05 |

外気圧は GPS の標高から標準大気で出した (天気で ±2% ずれる)。1 回転の空気は MAF (g/s) を回転
(1000rpm あたり) で割った 5000〜5900rpm の平均。

**床まで踏んでも力はほとんど増えない。** 吸気圧は外気の 96% → 100% に上がり、1 回転の空気は
10/16 昼より 5% 多いが、加速の差は −5〜+8% で、全開加速 1 回ごとのぶれ (±8%) の中に入る。
高回転では 102〜122 でもほぼ吸い切れている。10/16 夜は坂の補正が +4.0% (0.39 m/s²) と大きく、
比べる精度は他より低い。吸気温は 54℃ と高かったが、停車から発進した直後で、吸気温センサーが
熱を持っていた可能性がある (1 回転の空気はむしろ多い)。

### マフラー (フジツボ Wagolis 450-41521)

ログを取り始める (8/27) 前から付いている。メーカー値 (DY5W 1.5L で測定) は最大トルク
138.2 → 139.2 N·m (3670 → 3890rpm)、最大出力 101.5 → 103.1PS、4000〜6000rpm の加速音
94 → 101dB。純正のデータが無く、効果 (1〜2%) が推定のぶれより小さいので、この車での
効果は検証できない。1.3L は排気量が約 1 割小さいので、効果はこれより小さいと考えられる。

## 距離パルス

`0x420 B1` は 8bit ローリングカウンタ。

```
2568.14 パルス/km  (1パルス = 0.389387 m)
```

車速の積分より正確。積分は −0.25% の系統誤差があるのに対し、計数は ±0.02%。
ただし 255 パルス (99.3m) を超えて欠測すると周回を見失うため、受信間隔が
1.5秒を超えたら基準を取り直す (`internal/can/pulse.go`)。

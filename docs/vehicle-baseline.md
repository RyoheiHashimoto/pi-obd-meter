# この車の正常値 (2026-08 実測)

**「おかしいかも」と思ったときの比較対象。** 一般論を当てはめる前にここを見る。

対象: デミオ DY3W / ZJ-VE / FN4A-EL / 走行 10.9万km / 20年落ち

---

## 諸元

```
エンジン  ZJ-VE 1348cc 直4 DOHC 圧縮比10.0  S-VT (吸気カムのベーン式可変バルブ)
出力      91 PS (67 kW) / 6000 rpm
トルク    124 N·m (12.6 kgm) / 3500 rpm
変速機    FN4A-EL (Ford 4F27E) 4速AT
指定油    エンジンオイル 0W-20
```

**S-VT は油圧で動く。** エンジンオイルは潤滑だけでなく作動油でもあるので、
粘度を変えると応答に影響しうる。

---

## 健全性の基準値

すべて 2026-08-28〜29 の実測。**これより悪化したら要調査。**

| 項目 | 実測 | 判定の目安 |
|---|---|---|
| **短期燃料トリム** | 中央値 0.0% / 範囲 −7.0〜+7.8% | ±10%以内。中央値が0付近で対称なら正常 |
| **長期燃料トリム** | 中央値 −0.8% / 範囲 −2.3〜+2.3% | ±10%以内。偏りが小さいほど良い |
| **点火時期** | 平均 +21.2° / 高速 +26.1° BTDC | 進角したままならノッキング無し |
| **アイドル回転** | 731 rpm / σ=29 | σ 50rpm 以内なら安定 |
| **アイドル吸気圧** | 30 kPa (エアコンOFF) | 30〜40 kPa。50超なら圧縮漏れ等を疑う |
| **変速時間** | 平均 1.09秒 / 188回 | 1秒前後。長いと滑りや詰まり |
| **全開トルク** | 118.9 N·m @4000-4500rpm | カタログ 122 の 97% (誤差内) |

### 吸気圧はエアコンで大きく変わる

**混ぜて平均してはいけない。** アイドリング時の分布が3つの山に分かれる。

```
29〜32 kPa   30%   素の状態
41〜47 kPa   39%   何かが1つ乗っている
57〜63 kPa   21%   さらに乗っている
```

エアコンON時は消費が 0.75 → 1.50 L/h と倍になり、回転も 712 → 755 rpm に上がる。
**エアコンを分離せずに平均すると 43.5 kPa となり「やや高い」と誤判定する。**
実際に一度それをやった。

## 水温 — この車は元々高い

**一般論を当てはめて「98℃は高め」と誤判定した。** マツダ ZJ 系の設計値:

```
サーモスタット  開き始め 80〜84℃ / 全開 95℃
電動ファン      約100℃で高速 → 90℃まで下げる
```

**95℃は「異常」ではなく「設計上の全開点」。** 同じデミオの実測報告でも
街乗り 89℃、ラリー走行後で 103℃ とされている。

実測: 走行中の平均 91.4℃、最高 99℃ (渋滞時)。**完全に正常域。**

---

## 電気系 — 充電制御車である

**DY3W は充電制御車。** バッテリーは充電制御対応品が必要 (純正相当 55D23L)。

電圧が連続的でなく**二値に分かれる**のが特徴。中間がほとんど無い。

```
12.8〜13.0V  35%   抑制モード
13.5〜13.9V  60%   充電モード
13.1〜13.4V   5%   遷移中のみ
```

切り替えの条件も設計どおり。**軽加速のときだけ発電を絞る。**

| 状況 | 充電モード率 |
|---|---|
| 停車 | 78% |
| 加速25%超 | 69% |
| 減速・惰行 | 57% |
| 巡航 | 49% |
| **軽加速(10-25%)** | **30%** |

### 基準値 (2025-08 交換の caos で1年経過時点)

```
充電モード率  63〜64%   (2走行で再現)
アイドル電圧  13.58V    (回転が低いほど高い = オルタネータ正常)
最低電圧      12.65V
```

一般に充電制御車の充電モードは走行中の 1/4〜1/3 とされるが、**大容量品では
長くなる**。劣化すると内部抵抗が上がって充電制御が効かなくなり、この比率が
上がっていく。**年単位で追えば劣化の指標になる。**

## 変速機の速度と回転数

```
rpm = 車速 × ギア比 × 38.8
機械ギア比  1速 2.816 / 2速 1.498 / 3速 1.000 / 4速 0.726
```

定数 38.8 は「(1000/60) ÷ タイヤ周長 × 最終減速比」。
**ロックアップ中は剛結合なので、この式が厳密に成り立つ。**
`internal/can/slip.go` の `SlipCalibrator` はここから k を自動学習する。

| 車速 | 1速 | 2速 | 3速 | 4速 |
|---|---|---|---|---|
| 50 | 5481 | 2915 | 1946 | 1413 |
| **60** | — | **3499** | 2336 | 1696 |
| 80 | — | 4665 | 3114 | 2261 |
| **90** | — | 5248 | **3503** | 2543 |

**2速60km/h と 3速90km/h がトルクピーク(3500rpm)にちょうど乗る。**
峠で2〜3速を使うのは、この車の一番おいしい帯域を使っていることになる。

## 燃料センダーの限界

**両端でクリップする。** 給油量の自動算出が原理的に不正確になる原因。

```
下端  raw 22  (8.6%)
上端  raw 243 (95.3%)
```

満タン給油後、**11分間 95.29pt に張り付いたまま**で、燃料が減って測定範囲に
戻ってから初めて 90.6pt という実測値になった。**満タン時の読みは「上限に
達した」以上の情報を持たない。**

**係数 0.51 L/pt は中域でしか正しくない。** タンクは箱ではなく高さで断面積が
変わるため非線形。全域を跨いだ給油では 0.442 L/pt となり 13% ずれた
(実測 35.29L に対し 40.69L と算出、+15%)。

→ 満タン時は給油量を出さない実装にした (#148)。跳躍量は較正の材料として残す。

## 動力性能の推定方法とその限界

トルクセンサーは無いが、加速度から逆算できる。**ただし限界がある。**

```
F = m(1+λ)a + Crr·m·g + ½ρ·CdA·v²
T_engine = F × (r/FD) ÷ (機械ギア比 × η × K)

m=1100kg(乗員込) / λ=0.07(回転慣性) / Crr=0.012 / CdA=0.676
η=0.88(駆動系効率) / K=トルコン増幅 (滑りから概算、ロック時1.0)
r/FD は k から逆算: 1/(2π×0.06×k) = 0.0684 m
```

実測結果 (MAP≥95kPa = 全開、3速のみ、加速中):

| rpm | 最大トルク | カタログ | 比 |
|---|---|---|---|
| 3750-4000 | 116.4 N·m | 122 | 95% |
| 4000-4250 | 118.9 N·m | 122 | **97%** |
| 4250-4500 | 118.4 N·m | 120 | 99% |
| 5000-5250 | 103.9 N·m | 114 | 91% |

**カタログ比 3〜9%落ち。誤差の範囲内。** 仮定が5つ入っており、それぞれ
±10%動けば推定値も±10%動く。**0.5%の勾配だけで3%動く。**

### 使えるのは最大値だけ。中央値は無意味

同じ rpm・同じ MAP でも観測トルクは 60〜119 N·m とばらつく。理由は2つ。

1. **勾配** — 登坂中は重力に食われて加速しない
2. **最高速付近** — 全開でも加速しない (3速なら 135km/h 付近)。
   このとき測っているのは空気抵抗との釣り合いであって、エンジンの実力ではない

**低回転側はとくに危険。** 3速で低回転 = 低速であり、全開で15秒経っても
84km/h のままなら**それは登坂中**。そういうサンプルしか無い帯域では
トルクカーブが引けない。実際 3500rpm 以下は平坦路データが皆無だった。

### 勾配は分離できない

加速の不足分から勾配を逆算しようとしたが、**全サンプルが +0.1〜+15.9%
(中央値 +5.8%) となり成立しなかった。** 高速道路の勾配は通常 2〜3% で、
16% はありえない。

原因は上記の「最高速付近では全開でも加速しない」問題と、
**スロットル開度がトルクの指標にならない**こと (70%と90%でトルクが違う)。
MAP で絞っても、最高速付近の非加速状態と登坂を区別できない。

**勾配が要るなら GPS (#110) を入れること。** 現在の記録項目では届かない。

## 加速性能 (実測の最大値)

| 速度帯 | 最大加速度 |
|---|---|
| 0-19 km/h | 2.33 m/s² (0.24G) |
| 40-59 | 1.51 m/s² |
| 60-79 | 1.69 m/s² |
| 80-99 | 1.22 m/s² |
| 100-119 | 1.11 m/s² |

出力重量比 12.1 kg/PS (乗員込1100kg)。0-100km/h は 13〜14秒級で、
ヴィッツ1.3 (11.5) やフィット1.3 (11.9) と同クラス。

発進の 2.33 m/s² はトルコンの増幅が効いている領域。ここが鈍っていれば
クラッチの滑りや圧縮低下を疑う。

## 距離パルス

`0x420 B1` は 8bit ローリングカウンタ。

```
2568.14 パルス/km  (1パルス = 0.389387 m)
```

車速の積分より正確。積分は −0.25% の系統誤差があるのに対し、計数は ±0.02%。
ただし 255 パルス (99.3m) を超えて欠測すると周回を見失うため、受信間隔が
1.5秒を超えたら基準を取り直す (`internal/can/pulse.go`)。
